# Jiffo brand

## Logo

- `jiffo-wordmark.svg`: black letters with the green speed ball, for light backgrounds.
- `jiffo-wordmark-white.svg`: white letters with the bright green ball, for dark backgrounds.
- `jiffo-wordmark-mono.svg`: one colour (`currentColor`), for single-colour printing and UI use.

The wordmark has no dot on the j. The dot of the i is a green speed ball with two speed lines running back over the j.

## App icons

- `jiffo-icon-customer.svg`: the customer app icon, a white forward-leaning j with three speed lines on Jiffo green. Full-bleed square for the stores (iOS and Android apply their own corner masks).
- `jiffo-icon-agent.svg`: the agent app icon, the same mark in bright green on black.
- `*-rounded.svg`: rounded versions for documents, websites and presentations.
- `jiffo-mark.svg`: the small j mark (`currentColor`) used in notifications and in-app badges.
- `png/`: exports at 1024, 512, 192, 180 and 48 px, a 32 px favicon, and the wordmarks at 1600 px wide.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Jiffo green | `#0A7A4A` | Brand colour on light backgrounds, customer icon |
| Bright green | `#3DD68C` | Brand colour on dark backgrounds, agent icon |
| Ink | `#000000` | Wordmark letters on light backgrounds |
| Agent black | `#0B0B0B` | Agent icon background |

## Type

The letterforms come from Nunito Black, licensed under the SIL Open Font License 1.1. The interface typeface in the prototypes is Figtree.
